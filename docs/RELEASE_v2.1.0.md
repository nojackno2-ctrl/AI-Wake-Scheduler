# v2.1.0：自動模式每 10 分鐘偵測倒數、除錯日誌匯出

- **自動模式改為「開始後每 10 分鐘偵測倒數」**：從設定的開始時間起，每 10 分鐘讀取一次所有勾選 CLI 的倒數狀態（正在倒數的也會重讀），沒有倒數的 CLI 立即呼叫，倒數中的不呼叫；過了 24:00 停止，隔天開始時間重新開始。偵測間隔固定為 10 分鐘，設定裡的「額度自動重新整理分鐘」現在只影響額度看板。清單時間欄顯示「10分偵測 (下一次讀取時間)」。
- **修正**：自動模式在當晚最後一次檢查後，午夜過後可能在開始時間之前就直接呼叫 CLI；現在跨過 24:00 一律排到隔天的開始時間。
- **除錯日誌**：程式把排程判斷、每次額度讀取結果（用量、重置時間、是否倒數、讀取失敗原因）、CLI 呼叫與結果、背景錯誤逐行寫入 `%LOCALAPPDATA%\AI倒數喚醒\logs\debug-YYYYMMDD.log`，保留 14 天。
- **匯出除錯日誌…**：主視窗清單下方與系統匣選單新增此項目，把目前額度、設定、排程與所有日誌合併成單一 `.txt`，回報問題時附上即可。檔案包含 CLI 輸出與工作目錄路徑，分享前請自行檢查。

設定檔與排程檔格式不變，可直接覆蓋升級 v2.0.0；既有的自動模式排程會直接改用新的偵測方式。

## Windows x64 下載

- `AI-Wake-Scheduler_Setup_v2.1.0_x64.exe`：安裝版（可直接覆蓋升級 v2.0.0／v1.x）。
- `AI-Wake-Scheduler_Portable_v2.1.0_win-x64.zip`：免安裝版；解壓縮後執行 `AI倒數喚醒.exe`。
- `SHA256SUMS.txt`：以上兩個檔案的 SHA256 校驗碼。

不需安裝任何執行環境。使用前需安裝並登入所需的 CLI（agy、codex、claude）。
