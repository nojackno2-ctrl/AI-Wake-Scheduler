# v2.3.0：全新圖形化控制中心、倒數記憶、額度卡顯示每週倒數

- **全新圖形化介面**：主視窗改用 eframe／egui（GPU 繪製，仍為單一執行檔），預設深色主題並可一鍵切換淺色。5 個 CLI 以圓環卡片顯示 5 小時額度與重置倒數；排程以卡片呈現，含啟停開關與 24 小時偵測時段條；編輯器提供可拖曳的 24 小時時間軸（5 分鐘吸附）、間隔快選與 CLI 標籤；設定改為主視窗右側抽屜；即時終端輸出位於最右欄。
- **額度卡顯示每週倒數**：圓環固定顯示 5 小時視窗（沒有 5 小時視窗的 CLI 改顯示每週額度），卡片下方固定一列每週額度與重置倒數。每週額度用盡時整張卡片改紅框，圓環中央顯示紅字「用盡」與每週重置倒數。
- **記住倒數結束時間**：讀到倒數後不再依間隔重複讀取，倒數結束時間一到（且在偵測時段內）立即重讀並喚醒；只有尚未讀到倒數時才依間隔重試。主視窗看板與排程共用同一份倒數資訊。
- **CLI 更新改回提示**：有新版本時只提示並詢問是否開啟更新主控台，不再阻擋呼叫。
- **排程時段**：每筆排程設定每日開始與結束時間，以及檢查間隔（1–60 分鐘，整點刻度起算）。
- **修正**：Claude 喚醒後用量顯示 0% 時，誤判 5 小時倒數尚未開始，導致每 10 分鐘重複呼叫；儲存失敗時介面仍顯示已變更的狀態；關閉程式時手動執行無法取消；同一排程重複勾選同一 CLI 時呼叫兩次；額度已用盡但缺少重置時間時仍放行；Claude HTTP 429 快取被誤當成可喚醒；批次檔參數含雙引號與 `&` 時的注入風險；舊版排程資料升級時遺失狀態。

設定檔與排程檔可直接覆蓋升級 v2.2.0，舊排程資料自動遷移並保留歷史。

## Windows x64 下載

- `AI-Wake-Scheduler_Setup_v2.3.0_x64.exe`：安裝版（可直接覆蓋升級 v2.2.0 以前的版本）。
- `AI-Wake-Scheduler_Portable_v2.3.0_win-x64.zip`：免安裝版；解壓縮後執行 `AI倒數喚醒.exe`。
- `SHA256SUMS.txt`：以上兩個檔案的 SHA256 校驗碼。

不需安裝任何執行環境。使用前需安裝並登入所需的 CLI（agy、codex、claude）。
